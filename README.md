# IntroDev Landing Page

A landing page for **IntroDev**, a fictional ed-tech platform offering free beginner courses in Computer Science, Networking, Web Development, and Embedded Systems.

Built with pure HTML and CSS as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

**[Live Demo](https://kondrashar.github.io/Landing-Page/)**

## Sections

- **Hero** — headline, tagline, and sign-up CTA
- **Courses** — four course cards with images
- **Testimonial** — student quote
- **Call to Action** — enrollment prompt
- **Header / Footer** — logo and in-page navigation

## Built With

- HTML5
- CSS3 (Flexbox)
